Frequently askedعام سوالات

Can Qalam open my old InPage files?
Yes — open .inp/.int files directly from the File menu. Qalam Pro adds batch conversion of whole folders.

Does my writing leave my computer?
No. Qalam is an offline editor; text is sent to an AI service only if you set up the optional AI features with your own key and invoke them yourself. See the privacy policy.

Which fonts does Qalam use?
Noto Nastaliq Urdu is bundled. Any Urdu-capable Nastaliq or Naskh font installed on your system appears in the font menu automatically.
